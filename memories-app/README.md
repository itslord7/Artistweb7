# 📸 ذكرياتي — موقع تسجيل الذكريات

موقع بسيط لتسجيل الذكريات بواجهة عربية، مع **تسجيل دخول اختياري**:

- **بدون حساب (وضع الزائر):** تُحفظ الذكريات محليًا في متصفحك (`localStorage`).
- **مع حساب:** تُحفظ الذكريات على السيرفر وترتبط بحسابك، فتظهر على أي جهاز بعد تسجيل الدخول.

## التشغيل

لا يحتاج أي مكتبات خارجية — Node.js 18 أو أحدث فقط:

```bash
node server.js
```

ثم افتح المتصفح على: http://127.0.0.1:3000

يمكن تغيير المنفذ عبر متغير البيئة:

```bash
PORT=8080 node server.js
```

## الميزات

- إضافة ذكرى (عنوان، تاريخ، مشاعر، نص) وحذفها.
- تصفية الذكريات حسب المشاعر.
- تسجيل حساب جديد / تسجيل دخول / خروج.
- كلمات المرور مخزّنة مشفّرة (scrypt + salt) ولا تُرسل أبدًا للواجهة.
- الجلسات عبر كوكي `HttpOnly`.
- البيانات تُخزَّن في `data/db.json` (يُنشأ تلقائيًا).

## الواجهة البرمجية (API)

| المسار | الطريقة | الوصف |
|---|---|---|
| `/api/register` | POST | إنشاء حساب `{username, password}` |
| `/api/login` | POST | تسجيل الدخول `{username, password}` |
| `/api/logout` | POST | تسجيل الخروج |
| `/api/me` | GET | المستخدم الحالي |
| `/api/memories` | GET | قائمة ذكريات المستخدم (يتطلب دخولًا) |
| `/api/memories` | POST | إضافة ذكرى `{title, date, text, mood}` |
| `/api/memories/:id` | DELETE | حذف ذكرى |
